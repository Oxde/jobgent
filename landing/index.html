    What happens, in order

    1. Your facts, once

      Upload your CV and answer a few questions, typed or as a voice note. Jobgent turns it into one profile file you can read and edit. That file is the only thing it is ever allowed to say about you.

    2. A feed that is already filtered

      Every morning it pulls new postings, drops the ones that demand Dutch, keeps real internships, and scores the rest from 0 to 100 with reasons and gaps. You open it and the good ones are at the top.

    3. An application you approve

      One click per job: a one-page A4 CV in your own layout, reordered for this role, plus a short cover letter in your voice. It shows what it changed. You check it, then apply on the company's site or by email.

    It never invents experience

    Most AI CV tools will happily add Kubernetes to your skills because the posting asked for it. That gets you an interview you cannot survive.

    Jobgent can only select, reorder and rephrase what is in your profile. A second pass checks every claim in the finished CV and letter against your facts. If one is not backed, the application fails with the claim named, instead of being sent.

    Run it yourself

    It is a Python tool with an MCP server, so you can drive it from Claude, Cursor or any agent: “fetch jobs, show me the top ten, make the pack for number three.” There is also a small web app for the feed and your tracker.

    git clone https://github.com/Oxde/jobgent
cd jobgent && uv sync && uv run playwright install chromium
claude mcp add jobgent -- uv --directory $PWD run jobgent mcp

    You need an Anthropic API key (cents per application). A LinkedIn feed is optional and costs cents a day through Apify.
